4. Cell-by-Cell Architecture of the Notebook (16 Cells)

The notebook consists of 16 structured cells arranged into 7 logical engineering phases:

  1. Cells 1 and 2 (Setup and Installation): Installs mmengine, mmcv-lite, and mmaction2 directly from source, applying runtime compatibility patches for PyTorch 2.x arbitrary object unpickling.
  2. Cells 4 and 5 (Hardware Verification): Runs automated hardware inspection scripts checking GPU device availability, CUDA driver version, and allocating dedicated memory buffers.
  3. Cells 6 and 7 (Experiment Settings and Hyperparameters): Configures experiment variables, including the experiment name (v7_dedup), minimum joint motion threshold (MIN_MOTION = 5.0 with plank = 1.0 hold override), maximum fake frames allowed (MAX_FAKE_FRAMES = 30), and enables inverse-frequency class weighting to eliminate bias.

Data Hygiene Checks, Training Loop, Evaluation, and Benchmark Results

Part 2: Training & Benchmarks
  1. Cells 8 and 9 (Data Audit and Deduplication Engine): Applies the MD5 hashing algorithm over all 3D pose landmark matrices, purging 987 byte-identical duplicate clips, cross-checking candidates against the validation set to eliminate 4 overlap clips, and confirming zero leakage before model initialization.
  2. Cells 10 and 11 (Training Loop — PoseC3D SlowOnly-R50): Defines custom spatiotemporal augmentation (RandomRotateKeypoints within plus-or-minus 12 degrees), builds 3D limb heatmaps using Gaussian cylinder radius sigma = 0.6, and trains for 18 epochs using SGD with cosine annealing learning rate scheduling.
  3. Cells 12 and 13 (Dual Benchmark Evaluation): Runs automated validation inference using MMAction2 testing tools on both the 192 strictly unique clips and the 444 frozen baseline clips, calculating Top-1 accuracy, Macro Recall, and 95% Confidence Intervals.
  4. Cells 14 and 15 (Artifact Packaging and Export): Extracts the best-performing model checkpoint (best_acc_top1_epoch_10.pth), bundles the Python configuration file, and writes all training logs and metrics to a downloadable ZIP file.

5. Training Hyperparameters Table

Hyperparameter Configured Value Biomechanical / Algorithmic Rationale
Input Modality 3D Limb Heatmaps (sigma = 0.6) Connects joints into anatomical cylinders, preventing sagittal plane self-occlusion.
Temporal Sampling 48 Frames (Stride 2) Captures 2.5 seconds of physical movement (the natural duration of 1 full repetition).
Batch Size 16 Clips per Batch Optimal memory footprint fitting within 16 GB GPU VRAM.
Optimizer SGD (Momentum = 0.9) Standard robust optimizer for 3D spatiotemporal ResNet architectures.
Learning Rate 0.01 (Cosine Decay) Gradual cosine annealing preventing gradient explosion in early epochs.
Total Epochs 18 Epochs Sufficient convergence without overfitting on clean training data.
Class Weighting Inverse-Frequency Balanced Compensates for slight sample variations across the 7 exercise classes.
