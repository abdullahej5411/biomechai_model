# MediaPipe Pose Landmarker Model

This directory contains the official Google MediaPipe Pose Landmarker pre-trained model asset used for landmark extraction across the BioMechAI pipeline.

## Asset Information
- **Filename**: `pose_landmarker_lite.task`
- **File Size**: 5.78 MB
- **Model Type**: MediaPipe Pose Landmarker Lite (33 3D skeletal landmarks)
- **Coordinate System**: Normalized $(x, y, z)$ coordinates with visibility and presence confidence scores.
- **Tracking Frequency**: Optimized for real-time video stream landmark inference at >30 FPS on CPU.
